# RA2IniEditor 已知限制与使用边界

> 本文记录当前 RC 阶段已知限制。这里的内容不一定都是 Bug，很多是 RA2 / Ares / Phobos / MOD 生态本身带来的边界。

## 1. 第三方扩展字段覆盖不可能完全自动识别

Ares、Phobos 和各类私有扩展字段非常多，且不同 MOD 会自定义字段语义。当前工具会提供内置字段库、外部字段库和运行时推断，但不能保证覆盖所有第三方字段。

建议把项目专用字段写入：

```text
Dictionaries/User/custom_fields.ini
```

## 2. 软引用不会全部强制报错

RA2 INI 中存在大量软引用，例如动画、音效、资源、脚本、地形、VoxelAnim、AI 相关字段等。部分字段即使看起来像引用，也可能由游戏运行时、扩展引擎或资源包动态解析。

因此当前工具对部分低可信引用只给提示，不一定强制报错。

## 3. sound.ini 未加载时声音候选不会完整出现

`VoiceSelect`、`VoiceMove`、`DieSound`、`SinkingSound` 等字段会尽量识别为声音 Section 引用。

但如果当前项目没有加载 `sound.ini` 或 `soundmd.ini`，候选列表可能不完整，工具也不会强制把所有声音引用都判定为错误。

## 4. `1/0` 不会全局自动识别为布尔值

RA2 中大量字段可以使用 `0` 或 `1`，但它们不一定是布尔开关，也可能是数值、等级、索引或计数。

当前策略是：

- `yes/no` 自动识别为开关。
- `true/false` 自动识别为开关。
- `1/0` 仅在字段库或覆盖规则明确声明为布尔时按开关处理。

## 5. 资源检查依赖资源目录配置

Cameo、AltCameo、SHP、VXL、Palette 等资源检查依赖资源索引。如果没有配置资源目录，或资源没有被解包到可扫描目录中，工具只能给出有限提示。

建议在项目工具中维护资源索引，并在资源目录变化后重扫。

## 6. Quick Fix 只覆盖低风险场景

Quick Fix 目前主要处理注册表缺失、缺失引用占位、从同类型对象复制等低风险场景。

对于复杂字段语义、引擎扩展行为、AI 逻辑、脚本触发、地图专用规则等内容，仍应由用户人工判断。

## 7. INI 注释与格式会尽量保留，但不承诺完全等价

工具会尽量保留已有 INI 行结构、注释和顺序，但在新增、删除、重命名、复制、Quick Fix、批量处理等操作后，局部格式可能发生整理。

正式修改大型 MOD 前，建议配合 Git 或完整目录备份使用。

## 8. 深色主题仍可能存在少量系统控件边界

当前主要窗口和常用控件已经接入浅色 / 深色主题。少量系统弹窗、文件选择窗口或 WPF 默认控件弹层仍可能使用系统主题，这是正常边界。

## 9. 本工具不能验证游戏运行期全部行为

工具能检查 INI 结构、注册表、引用、字段类型和资源索引，但无法完全模拟 RA2 引擎、Ares、Phobos 或自定义 Hook 的运行期行为。

最终可玩性仍需要进游戏实测。
