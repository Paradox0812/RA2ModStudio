# 代码包清理说明

## 目的

RA2IniEditor 在频繁构建、测试和 UI 调整后会产生大量本地文件，例如 `bin/`、`obj/`、`.vs/`、`artifacts/`、`TestResults/`、日志和临时缓存。这些文件不属于源码，会让交接包变大，也可能让 Codex 或人工审查误读旧产物。

干净源码包只用于代码审查、交接和新对话恢复上下文，不代表发布包，也不会改变保存、Completion、Hover、Diagnostics、Undo/Redo、Field Registry 或 Shell UI 行为。

## 不应上传的内容

不要把以下内容放入源码包或提交到仓库：

- `.vs/`
- `bin/`
- `obj/`
- `artifacts/`
- `TestResults/`
- `.coverage/`
- `coverage/`
- `Logs/`
- `publish/`
- `*.user`
- `*.suo`
- `*.rsuser`
- `*.userosscache`
- `*.sln.docstates`
- `*.vsidx`
- `*.DotSettings.user`
- `*.nupkg`
- `*.snupkg`
- `*.zip`
- `*.7z`
- `*.rar`
- `*.log`
- `*.tmp`
- `*.cache`
- `*.bak`
- `*.orig`
- `*_wpftmp*`

历史人工测试 zip 可以继续留在工作区或历史记录中，但 `tools/package-source-clean.ps1` 生成的 clean source package 默认不会包含旧 zip。

## 必须保留的内容

干净源码包必须保留解决方案、源码、测试、文档、工具脚本和必要工程文件。特别要保留 BuiltIn v3.2 字段库：

```text
RA2IniEditor.Infrastructure/FieldRegistry/BuiltIn/builtin-yr-ares-phobos-fallback-v3.2.fields.json
```

脚本会在压缩后检查该文件是否存在；缺失时会直接失败。

## 运行清理预览

实际删除生成物前先运行预览：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\clean.ps1 -WhatIf
```

预览结果应只包含生成目录、缓存、日志、`.vs/` 和临时编译文件。如果看到源码、文档、BuiltIn JSON 或项目文件，不要继续执行实际清理。

## 实际清理

确认预览范围正确后执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\clean.ps1
```

清理后 `dotnet restore`、`dotnet build` 或 `dotnet test` 会重新生成 `bin/` 和 `obj/`。

## 生成干净源码包

当前脚本支持两个 Profile：

- `IdeOnly`：生成只包含 RA2IniEditor.IDE、Core、Infrastructure、测试、UIA 测试、工具、文档和 BuiltIn v3.2 的源码包，不恢复 legacy 表格式编辑器。
- `Full`：用于完整仓库形态，保留 legacy 根项目（如果当前工作区存在）。

生成 IDE-only 包：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\package-source-clean.ps1 -Profile IdeOnly
```

生成 Full 包：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\package-source-clean.ps1 -Profile Full
```

IDE-only 默认输出：

```text
artifacts/RA2IniEditor.IDE.SourceClean.zip
```

Full 默认输出：

```text
artifacts/RA2IniEditor.SourceClean.zip
```

`artifacts/` 是本地交付产物目录，已被 `.gitignore` 忽略；生成的 zip 不进入 git 跟踪。

## 解压检查

IDE-only 源码包应包含：

- `RA2IniEditor.IDE.sln`
- `RA2IniEditor.Core/`
- `RA2IniEditor.Infrastructure/`
- `RA2IniEditor.IDE/`
- `RA2IniEditor.Tests/`
- `RA2IniEditor.UiAutomationTests/`
- `docs/`
- `tools/`
- BuiltIn v3.2 JSON

Full 源码包在完整仓库中还应包含 `RA2IniEditor.sln` 和 legacy 根项目。当前 IDE-only 包不会恢复这些文件。

源码包不应包含：

- `bin/`
- `obj/`
- `.vs/`
- `artifacts/`
- `TestResults/`
- 旧 zip / 7z / rar
- 日志、缓存、临时文件和备份文件
- IDE-only 包不应包含 legacy 根 `RA2IniEditor.csproj`

`package-source-clean.ps1` 会自动执行这些关键检查。若检查失败，脚本会停止并输出具体缺失项或禁止项。

## 验证命令

清理和打包后建议执行：

```powershell
dotnet restore
dotnet build -c Release --no-incremental
dotnet test -c Release
```

如果没有清理 `bin/obj`，也可以用 `--no-restore` 做更快的回归检查。

## 暂缓重写的产品文档

本轮只修复 IDE-only 包基础设施，不重写产品文档。以下文档仍需后续人工复核或归档：

- `Docs/UserGuide.md`：仍提到 Key-Value 表格工作流。
- `Docs/ReleaseChecklist.md`：仍有偏通用 DataGrid UI 检查项，需要后续按 IDE Shell 体验复核。
- `Docs/FeatureOverview.md`：本轮未重写。
- `Docs/DeveloperNotes.md`：本轮未重写。

## Codex 崩溃或新对话恢复

如果 Codex 会话中断，优先提供以下内容恢复上下文：

1. 当前需求文档。
2. 最近一次交付摘要。
3. `artifacts/RA2IniEditor.SourceClean.zip`。
4. 已知禁止修改范围，例如保存、Completion、Hover、Diagnostics、Undo/Redo、BuiltIn v3.2、Field Registry 和 Shell UI 语义。

干净源码包可以减少旧构建产物和缓存对新对话的干扰，让后续审查更稳定。
